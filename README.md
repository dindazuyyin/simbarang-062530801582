# SIM-Barang

## Deskripsi Proyek
SIM-Barang adalah Sistem Pengelolaan Inventaris Barang Jurusan yang digunakan untuk mencatat, mengelola, dan memantau data barang di lingkungan laboratorium dan jurusan.

## Tujuan
- Mempermudah pencatatan data inventaris barang.
- Membantu pengelolaan barang masuk dan barang keluar.
- Menyediakan informasi jumlah dan kondisi barang.
- Menerapkan teknologi HTML, CSS, JavaScript, PHP, dan MySQL.

## Konsep HTTP Request dan HTTP Response

**HTTP Request** adalah permintaan yang dikirimkan oleh browser kepada server untuk meminta halaman atau mengirimkan data.

**HTTP Response** adalah tanggapan yang diberikan server kepada browser setelah memproses permintaan tersebut. Respons dapat berupa halaman web, data, atau kode status seperti 200 (berhasil) dan 404 (halaman tidak ditemukan).

- PHP Native
- MySQL

- Laragon
